# Pronúncia dos sobrenomes · Cartório de Restauração Identitária

Página `ouvir.html?s=ID1,ID2,...&d=ID` usada pelos links das certidões do Cartório.

- `a/m/ID.m4a` e `a/h/ID.m4a`: pronúncia em voz feminina e masculina.
- `d/ID.json`: nome, significado e origem de cada sobrenome.

Vozes sintéticas geradas a partir do corpus OpenSLR 86 (Google, CC BY-SA 4.0) e dos modelos MMS (Meta). A pronúncia é uma aproximação.
